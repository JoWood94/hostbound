# NEON OVERDRIFT

Infinite runner + bullet hell + roguelike synergies. Mobile first, vanilla JS, Canvas 2D.

Design: [GDD.md](GDD.md)

## Dev

```bash
npm install
npm run dev      # http://localhost:5173/neon-overdrift/  (add --host to test on phone over LAN)
npm run build    # dist/
```

Controls: drag to move, swipe up = jump, swipe down = dash. Desktop: A/D or arrows, Space, Shift.
